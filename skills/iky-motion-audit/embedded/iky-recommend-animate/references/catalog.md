# Animation Library Catalog

Snapshot: 2026-08-05. Verify current official docs, repository activity, package version, and license before committing a production dependency. “Cost” is a relative runtime/asset risk, not a fixed bundle-size claim.

## Legend

- **Cost:** L = small DOM/native layer, M = noticeable runtime or authored asset, H = canvas/WebGL/WASM/continuous rendering.
- **Rendering:** `SSR shell` means semantic markup can render on the server but animation initializes on the client. `Client` means the visual runtime needs DOM/canvas/WebGL/WASM. In React Server Components, isolate either case behind a client component.
- **Accessibility:** “manual” means explicitly implement reduced motion, focus/reading-order preservation, pause controls where relevant, and keyboard/touch equivalents.
- **Status:** current snapshot only; “legacy” means do not choose for greenfield without a migration constraint.

## Hard Exclusions Before Scoring

Reject a candidate before comparing aesthetics when any of these is true:

1. Its license or hosted-service terms do not fit the product.
2. Its runtime cannot preserve required SSR/RSC content or target-browser support.
3. The experience cannot provide a reduced-motion/static path or equivalent keyboard/touch access.
4. The team cannot own its authoring format, shaders, asset pipeline, or cleanup lifecycle.
5. The expected visual value does not justify its continuous CPU/GPU/network cost.
