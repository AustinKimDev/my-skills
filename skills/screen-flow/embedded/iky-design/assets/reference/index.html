Typography / Usage

혼용·반응형·검증 규칙

한글·영문·숫자 혼용

한글과 영문 본문은 같은 Pretendard로 연결합니다. 본문에 영문이 있다고 별도 글꼴을 섞지 않습니다. 가격의 숫자와 단위는 별도 요소로 나눠 크기와 굵기를 조절하고, 자간으로 숫자 폭을 강제로 맞추지 않습니다.

모바일과 큰 글자

모바일 입력은 16px 이상으로 유지합니다. 좁은 화면과 큰 글자 설정에서는 제목을 줄바꿈하고 본문 행간을 보존합니다. 버튼을 눌리거나 작게 축소해 맞추지 않습니다. 긴 설명은 읽을 수 있는 줄 길이로 제한하고 가로 스크롤을 만들지 않습니다.

대비와 폰트 로딩

일반 텍스트는 배경 대비 4.5:1 이상을 기준으로 확인합니다. 오류·선택·활성은 굵기, 텍스트, 아이콘을 함께 사용합니다. 웹 폰트가 실패하면 시스템 글꼴로 대체되므로 배포 전 실제 폰트 로딩과 한글·영문·숫자 렌더링을 모두 확인합니다.

앱 적용 전 검증

앱 적용 전에는 iOS·Android에서 중간 굵기 400·500·600·700·700·700·800이 구분되는지 확인합니다. HTML 시트 검증은 실제 기기 검증을 대신하지 않습니다. 기존 Typography.tsx의 h1–h6·subtitle1–2·body1–2·caption API는 앱 적용 시 이 역할 표에 매핑하며, 시트 작업만으로 API를 삭제하지 않습니다.

에셋 제작·검수 기준 전문

주요 오브젝트 하나와 보조 장식 소수만 사용합니다. 조명은 앞·위쪽의 부드러운 스튜디오 조명, 재질은 매끈한 광택이며 거친 클레이·강한 반사·사실적인 크롬을 피합니다. 관련 에셋의 원근과 시각적 무게를 맞춥니다.

정사각 PNG의 실제 알파 투명도를 확인합니다. 피사체와 장식 주변에 5–10% 여백을 남기며 흰 사각형·체크무늬·검은 배경을 이미지에 넣지 않습니다. 글자·가격·CTA는 접근 가능한 HTML로 분리합니다.

핑크·피치·골드·라벤더·민트 중 주색 하나와 보조색 하나를 고릅니다. 모든 색을 동시에 쓰지 않습니다. 기능 아이콘과 사용자 사진, 브랜드 로고는 일러스트 재질로 바꾸지 않습니다.

52 × 56px 및 32–40px 실제 크기에서 인식성을 확인하고, 밝은 배너·어두운 바탕의 알파 가장자리를 비교합니다. 앱 적용용 파생본은 가장 큰 표시 크기의 최대 3배를 기준으로 만들고 원본은 보존합니다. 현재 시트는 기준 원본을 비교용으로 사용합니다.

새 멤버십 하트 패스 생성본은 알파 대신 체크무늬가 포함되어 검수 탈락했습니다. 화면에는 적용하지 않았으며 새 에셋으로 승인된 상태가 아닙니다.

모션 실험실

Motion 12.23.24 · 시트 적용

버튼을 눌러 비교합니다. 자동 반복이나 클릭 시 확대·축소는 사용하지 않습니다.

01 · 공 이동 / Easing

시작은 빠르게, 끝은 부드럽게 멈춥니다. 위치 변화가 의미 있는 탭·선택 표시의 기본입니다.

150–1000ms 비교 · cubic-bezier(.22, 1, .36, 1) · 이동 중 다시 누르면 현재 위치에서 반대로 이동합니다.

02 · 공 이동 / Spring

위치가 바뀌는 물리적 동작을 비교하는 실험입니다. 일반 버튼·셀렉트에는 탄성이나 스케일 효과를 넣지 않습니다.

stiffness 180 · damping 22 · mass 1. 약한 탄성만 사용하며, 제품 UI에 자동으로 확대 적용하지 않습니다.

03 · 순차 등장 / Stagger

처음 나타나는 소수의 항목에만 짧은 순서를 줍니다. 검색 결과나 반복 데이터 갱신은 기다리게 하지 않습니다.

1234

항목당 40ms 간격 · 180ms 등장 · y 8 → 0 · opacity 0 → 1. 크기는 바뀌지 않습니다.

04 · 표면 전환 / Fade

팝오버처럼 새로운 정보를 드러낼 때 쓰는 짧은 전환입니다. 레이아웃 공간을 유지해 주변이 흔들리지 않습니다.

유유나님이 활동 중이에요

160ms 투명도 전환 · scale 없음 · 제어 버튼은 전환 중에도 사용할 수 있습니다.

상황 사용 규칙 금지·예외
버튼·셀렉트 트리거 색·테두리 상태만 120–150ms로 전환합니다. 누른 위치와 크기는 유지합니다. scale, 큰 탄성, 클릭 영역 이동 금지
선택 팝오버 Motion 등장160ms / 퇴장100ms, 최대4px 이동. 재입력 시 이전 전환을 중단하고 새 상태를 반영합니다. 퇴장 중 클릭 차단, 초점은 즉시 트리거로 복귀
탭·차트 탭 밑줄240ms, 차트 전환220ms. 상태값은 즉시 갱신합니다. 모든 콘텐츠에 순차 지연을 강제하지 않습니다.
라이브러리 이 HTML 시트는 Motion의 JavaScript API를 사용합니다. React 웹에서는 Motion React를 우선 검토합니다. anime.js·react-spring을 동시에 도입하지 않습니다. 네이티브 앱 라이브러리 결정·설치는 별도 범위입니다.
동작 줄이기 prefers-reduced-motion에서는 이동·탄성·순차 지연 없이 최종 상태를 즉시 표시합니다. 의미·선택 상태는 그대로 유지합니다. 자동 무한 반복은 사용하지 않습니다.

Motion 공식 시작 가이드 · animate API · 라이선스 전문. 시트의 로컬 vendor 파일을 사용하므로 모션 라이브러리를 매번 외부에서 받지 않습니다.

컴포넌트 상태 전환 규칙

아래 문서와 실제 견본에 같은 규칙 적용

선택과 입력

버튼·입력·라디오·체크박스·별점은 색, 테두리, 채움만 150ms로 전환합니다. 눌림에 scale을 사용하지 않습니다. 박스형 ON/OFF는 상태 텍스트를 즉시 갱신하고 색으로 함께 구분합니다. 스위치 손잡이는 180ms로 이동합니다.

탭과 데이터

세그먼트 선택 배경은 Motion으로 220ms 이동합니다. 이동 중 다시 선택하면 현재 위치에서 새 선택으로 향합니다. 플랫 탭 밑줄은 240ms입니다. 표의 검색·정렬·페이지 전환은 즉시 적용하고, 행 선택 색만 150ms로 전환합니다. 차트는 값 갱신 후 220ms 등장합니다.

떠 있는 화면과 피드백

셀렉트·날짜·시간 팝오버는 160ms 등장하고 100ms 퇴장합니다. 모달은 4px, 설정 패널은 8px 이내에서 160ms 등장합니다. 아코디언 내용과 토스트는 위치 이동 없이 160ms로 나타납니다. 네이티브 다이얼로그 닫힘과 포커스 복귀는 지연하지 않습니다.

움직이지 않는 기준

본문·가격·표 데이터·정적 카드에는 자동 등장이나 반복 애니메이션을 붙이지 않습니다. 슬라이더 드래그는 손가락을 즉시 따라갑니다. 동작 줄이기가 켜지면 전환과 지연을 생략하되 선택 상태, 오류, 포커스는 그대로 표시합니다. 애니메이션이 입력을 잠그거나 값을 늦게 반영하지 않습니다.

셀 복사·넘침 처리 규칙과 API 예시 
const tableOptions = {
  isCopyable: true,
  overflowMode: "scroll", // "scroll" | "wrap"
};
const priceColumn = {
  display: row => row.priceLabel, // "9,900원"
  copyData: row => row.price,     // "9900"
};

isCopyable이 false이면 복사 버튼을 표시하지 않습니다. copyData는 표시 문구와 별개인 원본 값을 지정합니다. 이 표의 요금은 ‘9,900원’으로 표시하고 ‘9900’을 복사하며, 식별자는 전체 문자열을 복사합니다. 이름 옆 복사 아이콘은 전체 식별자를 복사하고, 이름을 누르면 상세 화면에서 원문을 확인할 수 있습니다. 기본 목록에는 식별자 보조 줄을 쌓지 않습니다. 복사 완료는 아이콘과 안내 문구로 알립니다. 권한 문제로 실패하면 성공으로 표시하지 않고 안내합니다.

scroll은 열 너비와 한 줄 표현을 유지하고 표 영역 안에서만 가로 이동합니다. 넘침이 실제로 있을 때 안내를 표시하며 키보드로도 스크롤할 수 있습니다. wrap은 전체 폭 안에서 긴 문자열을 줄바꿈하고 행 높이를 늘립니다. 말줄임표로 원문을 숨기지 않으며, 선택·정렬·복사 상태는 보기 전환 후에도 유지합니다.
