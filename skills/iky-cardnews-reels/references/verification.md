# Verification and hand-off

## Cards

- The title face loaded (the export script prints it). Every PNG is 1080x1350.
- Inspect the contact sheet for the whole set and at least the cover and any card with placed artwork at full size.
- Look for: placed artwork sitting across a slot border or overlapping its neighbour, a subject hidden by the headline, text touching an edge, a sticker covering the focal detail or the tag, a gloss overlapping its keyword, an auto-shrunk line.
- Alternative text for every card describes the copy and the scene.

## Reel

- Read the encoded file back: duration, 1080x1920, frame rate, codec, one audio track.
- Inspect stills decoded from the file (not from the canvas) covering every scene and at least one cut.
- Measure the soundtrack, and the audio decoded back out of the MP4, against the targets in [reels](reels.md).
- Not covered unless actually done: playback on a phone, inside the Instagram app, and how it sounds.

## Report

Say what was produced, where it is, what was inspected and how (full size, contact sheet, decoded stills, measurements), and what was not checked. Keep these separate:

- **Pre-publication checks.** Facts the code could not settle: feature flags in production, store availability, catalog contents. Name the card or scene to remove if a flag is off.
- **Provenance.** Which images are generated, which artwork is real, which graphics are explanatory.
- **Status.** Not posted, not scheduled. Preview pages and repository changes follow the user's own authorization.

Keep the brief, the worker's result record, the originals and a short README beside the deliverables so the set can be rebuilt. Remove superseded exports instead of leaving two versions side by side.
