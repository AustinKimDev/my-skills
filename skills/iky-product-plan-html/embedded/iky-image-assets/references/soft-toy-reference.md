# Soft toy illustration reference

Use this optional reference only when the project selects a rounded, glossy 3D illustration family. It does not define the style of user photos, uploaded creator content, logos, functional icons or every background.

## Inspected visual anchor

The [bundled trophy](../assets/references/soft-toy-trophy.png) is an unbranded, maintainer-supplied visual reference, generalized from a project asset. The original pixels are retained: 1254 × 1254 with an alpha channel. It contains a gold trophy, pink hearts, mint/yellow accents and a lavender base. Colored edge residue is visible at large size; match the art direction rather than extraction defects. Alpha metadata is not edge-quality certification.

Use the requested project's current asset guide and inspected references first. This image is a style example, not the latest source for another project or a requirement to reuse its subject.

## Apply the visual language

Match rounded, puffy toy forms, smooth softly glossy surfaces, broad highlights, soft above/front studio light and a front or gentle three-quarter view. Gold can be bright; avoid rough/chalky clay, chrome, mirror reflections and harsh glare. Use one dominant and one supporting color plus restrained accents from the project's chosen palette.

For isolated objects, apply [the cutout recipe](deliverables.md#isolated-decorative-object) and [production cleanup](production.md#alpha-and-edge-cleanup). For backgrounds, apply [the background recipe](deliverables.md#background-or-hero-scene): opacity, crop and text-safe space are separate decisions from material style.

Check the actual placement before choosing detail density. A 52 × 56 logical-pixel trophy or 32–40px supporting object is an illustrative compact layout, not a global sizing rule. Do not enlarge a promotion row merely to accommodate a detailed illustration.

Use the generic soft-toy recipe with the inspected image as a style-only reference, the requested new subject, actual placement and selected delivery recipe. Keep project palettes, prompt records and private source paths in the project's own asset guide.
